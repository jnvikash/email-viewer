🔧 THE FIX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem:
  Error: not an OLE2 structured storage file

Root Cause:
  Your .msg files were RFC 822 MIME format (text-based email),
  not OLE2 binary (Outlook) format.

Solution:
  Updated msg_parser.py to detect and handle both formats:
  
  1. Check file magic bytes → determine format
  2. If OLE2 (binary) → use extract-msg library
  3. If MIME (text) → use Python email.parser library
  4. Fallback → skip with debug log

Result:
  ✅ Successfully indexed 19 MIME format .msg files
  ✅ All metadata extracted (subject, sender, date, body)
  ✅ Attachments listed correctly
  ✅ Ready for production use

🚀 HOW TO START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open terminal and navigate to project:
   $ cd /home/vikash/email-viewer

2. Start the app:
   $ python run.py
   Email Viewer running at http://localhost:5000

3. Open browser:
   → http://localhost:5000

4. Create password (first run only):
   → Enter any password → Sign in

5. Configure email folder:
   → Click Settings (⚙️)
   → Root folder path: /mnt/c/Users/User/Documents/msg
   → Save Path

6. Start indexing:
   → Click "Start Indexing"
   → Watch progress bar
   → Wait for "Indexing complete!"

7. Browse emails:
   → Left pane: Click folder to load emails
   → Middle pane: Sort/filter emails as needed
   → Right pane: Click email to read full content
   → Search bar: Find emails by keyword
